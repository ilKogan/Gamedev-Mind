### Инструкция по установке ZeroTier на Raspberry Pi 4

ZeroTier — это программа для создания виртуальных частных сетей (VPN), которая позволяет объединять устройства в одну локальную сеть через интернет. Вот пошаговая инструкция для установки ZeroTier на Raspberry Pi 4.

---

#### **Шаг 1: Подготовка Raspberry Pi**
1. Убедитесь, что ваш Raspberry Pi 4 работает на актуальной версии операционной системы (например, Raspberry Pi OS).
   - Проверьте обновления:
     ```bash
     sudo apt update && sudo apt upgrade -y
     ```
2. Перезагрузите устройство после обновления:
   ```bash
   sudo reboot
   ```

---

#### **Шаг 2: Установка ZeroTier**
1. Добавьте репозиторий ZeroTier:
   ```bash
   curl -s https://install.zerotier.com | sudo bash
   ```
   - Эта команда автоматически скачает и установит ZeroTier на ваш Raspberry Pi.

2. После завершения установки проверьте статус службы ZeroTier:
   ```bash
   sudo systemctl status zerotier-one
   ```
   - Если служба активна, вы увидите сообщение `active (running)`.

---

#### **Шаг 3: Присоединение к сети ZeroTier**
1. Создайте сеть ZeroTier на официальном сайте:
   - Перейдите на [ZeroTier Central](https://my.zerotier.com/) и войдите в свою учетную запись.
   - Создайте новую сеть, нажав кнопку "Create a Network".
   - Скопируйте **Network ID** созданной сети.

2. Присоедините Raspberry Pi к сети:
   ```bash
   sudo zerotier-cli join <NETWORK_ID>
   ```
   - Замените `<NETWORK_ID>` на скопированный идентификатор сети.

3. На сайте ZeroTier Central перейдите в раздел созданной сети и найдите ваше устройство (Raspberry Pi) в списке членов сети.
   - Нажмите "Auth" рядом с устройством, чтобы авторизовать его.

4. Проверьте статус подключения:
   ```bash
   sudo zerotier-cli listnetworks
   ```
   - Вы должны увидеть вашу сеть с пометкой `OK`.

---

#### **Шаг 4: Настройка IP-адреса**
1. Если IP-адрес не был автоматически назначен, вы можете назначить его вручную:
   - На сайте ZeroTier Central найдите ваше устройство и введите желаемый IP-адрес в поле "Managed IPs".

2. Проверьте сетевое подключение:
   ```bash
   ping <IP_адрес_другого_устройства_в_сети>
   ```

---

### **Рекомендации по безопасности**

1. **Используйте сложные пароли**:
   - Убедитесь, что ваша учетная запись на ZeroTier Central защищена надежным паролем.

2. **Ограничьте доступ к сети**:
   - Авторизуйте только те устройства, которым действительно нужен доступ к вашей ZeroTier-сети.
   - Регулярно проверяйте список подключенных устройств.

3. **Включите шифрование**:
   - ZeroTier использует шифрование по умолчанию, но убедитесь, что опция "Encryption" включена в настройках сети на сайте ZeroTier Central.

4. **Обновляйте программное обеспечение**:
   - Регулярно обновляйте ZeroTier и операционную систему Raspberry Pi, чтобы избежать уязвимостей.

5. **Используйте файрвол**:
   - Настройте правила файрвола на Raspberry Pi, чтобы ограничить входящие и исходящие соединения только необходимыми портами.

6. **Мониторинг трафика**:
   - Используйте инструменты мониторинга (например, `iftop` или `nload`) для отслеживания сетевой активности.

7. **Двухфакторная аутентификация (2FA)**:
   - Включите двухфакторную аутентификацию для вашей учетной записи ZeroTier Central, если это возможно.

8. **Резервное копирование конфигурации**:
   - Сохраните резервную копию конфигурации ZeroTier (`/var/lib/zerotier-one`) на случай необходимости восстановления.

---

Следуя этой инструкции, вы сможете успешно установить и настроить ZeroTier на Raspberry Pi 4, а также обеспечить безопасность вашей сети.
