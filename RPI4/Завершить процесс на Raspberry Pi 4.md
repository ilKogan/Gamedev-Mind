---

#### 1. **Найти PID процесса**
- Используйте `ps` или `pgrep`:
  ```bash
  ps aux | grep имя_процесса
  ```
  или
  ```bash
  pgrep имя_процесса
  ```

---

#### 2. **Завершить процесс**
- Используйте `kill` с найденным PID:
  ```bash
  sudo kill PID
  ```
- Если процесс не завершается, принудительно:
  ```bash
  sudo kill -9 PID
  ```

---

#### 3. **Завершить процесс по имени**
- Используйте `pkill`:
  ```bash
  sudo pkill имя_процесса
  ```

---

#### 4. **Использование `htop`**
- Установите `htop` (если не установлен):
  ```bash
  sudo apt-get install htop
  ```
- Запустите `htop`:
  ```bash
  htop
  ```
- Найдите процесс, выделите его и нажмите `F9` для завершения.

---

#### 5. **Графический интерфейс**
- Используйте системный монитор (например, в Raspbian) для завершения графических приложений.

---

**Примечание:**  
- Заменяйте `имя_процесса` на имя вашего процесса (например, `python3`, `chromium` и т.д.).
- Используйте `sudo` для завершения системных процессов.
